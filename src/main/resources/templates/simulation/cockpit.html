Academic Evaluation • Java Architecture

AETHER Lite — Technical & OOP Specifications

Detailed architectural overview demonstrating the Java principles, patterns, and modules implemented per the AETHER Lite Cahier des Charges v2.

📐 1. Modèle Conceptuel UML (Annexe B) & Polymorphisme

Toutes les entités de simulation implémentent le polymorphisme et le découplage par interfaces :

  • Inspectable (Interface) : Contrat d'inspection générique fournissant getInspectableId(), getInspectableName(), getInspectableType() et getInspectionDetails().
  • AbstractAgent (Classe abstraite) : Encapsule les coordonnées spatiales $(x,y)$, la satisfaction, l'état d'activité, et définit la méthode abstraite step(SimulationContext).
  • CitizenAgent : Modélise la population avec routine temporelle (repos, trajet domicile-travail, bureau, dépenses, budget, bonheur).
  • VehicleAgent : Navigation autonome sur graphe routier, vitesse dynamique asservie à la congestion, reroutage A*.
  • BusinessAgent : Modélise les entreprises urbaines (masse salariale, recrutements, chiffre d'affaires, profits).

⚡ 2. Algorithmique & Structures de Données (MOD-03)

  • Algorithme A* (A-Star) : Implémenté dans AStarRoutingEngine.java avec file de priorité PriorityQueue<NodeRecord> ordonnée selon $f(n) = g(n) + h(n)$.
  • Heuristique Admissible $h(n)$ : Distance euclidienne divisée par la vitesse maximale admissible ($v_{\max} = 90$ km/h), garantissant l'optimalité du chemin.
  • Coût Réel $g(n)$ avec Congestion : Le coût d'un tronçon prend en compte sa longueur et sa vitesse effective réduite par le ratio de saturation.
  • Évitement d'Obstacles : Si un tronçon est marqué isClosed = true (Scénario What-If 🚧), $A^*$ détecte le blocage et recalcule automatiquement un itinéraire de contournement.

⚙️ 3. Concurrence & Robustesse (Java Concurrency)

  • ScheduledExecutorService : Cadence les ticks de simulation en arrière-plan sans bloquer les requêtes Web ou le thread UI (1x = 1000ms, 2x = 500ms, 5x = 200ms, 10x = 100ms).
  • Variables Atomiques : AtomicBoolean pour l'état d'exécution, AtomicLong pour l'horloge virtuelle, AtomicInteger pour le décompte de véhicules sur chaque route.
  • Collections Concurrentes : ConcurrentHashMap pour le graphe et les agents, CopyOnWriteArrayList pour les abonnés (listeners), ConcurrentLinkedDeque pour les événements.
  • Isolation des Défaillances (NFR-05) : L'exécution concurrente parallelStream() dans AgentEngine isole chaque agent dans un bloc try-catch pour qu'une exception isolée ne crash jamais la simulation.

🔬 4. Moteur de Scénarios What-If & Records Java 21 (MOD-07)

Implémente le pattern Memento / Snapshot via les records Java 21 :

  • SimulationSnapshot (Record) : Capture immuable des métriques de référence (Baseline).
  • Analyse Différentielle ($\Delta$) : Calcul automatisé des deltas de congestion, vitesse, satisfaction, emploi et PIB avec génération de recommandations d'intelligence décisionnelle.
